<h1>Eren Rent a Car API – Documentation</h1>
<p>Eren Rent a Car API uses Bearer Authentication to authenticate requests when interacting with your registered endpoints. Access tokens are renewed based on the response expiration time.</p>

<h2>1. AUTHENTICATION (POST)</h2>
<p><strong>Request URL:</strong> https://api.erenrentacars.com/v1/oauth/token</p>
<h3>Request Parameters</h3>
<table>
<tbody><tr><th>Parameter</th><th>Type</th></tr>
<tr><td>username</td><td>string</td></tr>
<tr><td>password</td><td>string</td></tr>
</tbody></table>
<h3>1.1. Example JSON Response</h3>
<pre>{
  "access_token": "6f4bc6317b96dfc83ead95114cc23c46",
  "token_type": "Bearer",
  "access_expires_at": "2025-06-19T23:59Z"
}</pre>

<h2>3. SEARCH AVAILABLE CARS (POST)</h2>
<p><strong>Request URL:</strong> https://api.erenrentacars.com/v1/search</p>

<h3>3.1. Required HTTP Headers</h3>
<table>
  <tbody><tr><th>Header</th><th>Value</th><th>Description</th></tr>
  <tr><td>Content-Type</td><td>application/json</td><td>Specifies that the body is JSON</td></tr>
  <tr><td>Authorization</td><td>Bearer &lt;access_token&gt;</td><td>OAuth2 access token</td></tr>
</tbody></table>

<h3>3.2. Request Parameters</h3>
<table>
<tbody><tr><th>Parameter</th><th>Type</th><th>Description</th></tr>
<tr><td>pickup_id</td><td>integer</td><td></td></tr>
<tr><td>dropoff_id</td><td>integer</td><td></td></tr>
<tr><td>pickup_date</td><td>Datetime (UTC)</td><td>YYYY-MM-DDTHH:MMZ</td></tr>
<tr><td>dropoff_date</td><td>Datetime (UTC)</td><td>YYYY-MM-DDTHH:MMZ</td></tr>
<tr><td>currency_code</td><td>String</td><td>EUR, USD, TRY</td></tr>
</tbody></table>

<h3>3.3. Example JSON Request</h3>
<pre>{
  "pickup_id": 1,
  "dropoff_id": 1,
  "pickup_date": "2025-07-25T15:00Z",
  "dropoff_date": "2025-08-05T15:00Z",
  "currency_code": "EUR"
}</pre>

<h2>4. BOOK (POST)</h2>
<p><strong>Request URL:</strong> https://api.erenrentacars.com/v1/book</p>

<h3>4.1. Required HTTP Headers</h3>
<table>
  <tbody><tr><th>Header</th><th>Value</th><th>Description</th></tr>
  <tr><td>Content-Type</td><td>application/json</td><td>Specifies that the body is JSON</td></tr>
  <tr><td>Authorization</td><td>Bearer &lt;access_token&gt;</td><td>OAuth2 access token</td></tr>
</tbody></table>

<h3>4.2. Request Parameters</h3>
<table>
<tbody><tr><th>Parameter</th><th>Type</th><th>Description</th></tr>
<tr><td>booking_reference</td><td>string</td><td>Your booking reference ID</td></tr>
<tr><td>search_request_id</td><td>string</td><td>ID provided by our API in the "Search" request.</td></tr>
<tr><td>quote_id</td><td>string</td><td>ID provided by our API in the "Search" request.</td></tr>
<tr><td>first_name</td><td>string</td><td>Customer first name</td></tr>
<tr><td>last_name</td><td>string</td><td>Customer last name</td></tr>
<tr><td>email</td><td>string</td><td>Customer email address</td></tr>
<tr><td>phone</td><td>string</td><td>Customer phone number</td></tr>
<tr><td>flight_number</td><td>string</td><td>Customer Flight Number</td></tr>
<tr><td>driver_age</td><td>int</td><td>Driver Age</td></tr>
<tr><td>id_number</td><td>string</td><td>Customer Identity number</td></tr>
<tr><td>passport_number</td><td>string</td><td>Customer Passport Number</td></tr>
<tr><td>comment</td><td>string</td><td>Customer additional comments</td></tr>
<tr><td>extras</td><td>array</td><td>Array of Extra objects</td></tr>
</tbody></table>
<h3>4.3. Example JSON Request</h3>
<pre>{
  "booking_reference": "YOUR RESERVATION ID",
  "search_request_id": "22688e3c-b0e3-4a5c-a0fb-9fcce1cd33b2",
  "quote_id": "2f7ce962396ba2bc02f2b33e0ee5f6bc",
  "first_name": "John",
  "last_name": "Doe",
  "email": "mail@domain.com",
  "phone": "+901234567891",
  "flight_number": "TK3501",
  "driver_age": 22,
  "id_number": "ID011111111",
  "passport_number": "PS011111111",
  "comment": "Test reservation",
  "extras": [
    {
      "service_id": 1
    },
    {
      "service_id": 2
    }
  ]
}</pre>

<h3>4.4 Example JSON Response</h3>
<pre>{
  "status": "success",
  "booking_reference": "YOUR RESERVATION ID",
  "booking_number": "ERN67C901A252235" //Our unique booking number
}</pre>
