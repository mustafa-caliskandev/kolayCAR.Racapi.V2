Overview

One flow, documented end to end

KolayCAR Broker API exposes the public rental flow used by partner applications. This portal only shows the endpoints from the Postman document, so customers see a focused integration guide instead of the full internal API surface.

1Authenticate and receive a token.
2Load countries, cities, locations, vehicles, and extras.
3Create, save, query, or cancel reservations.

Quick Start

Send the token with every protected request

Start with POST /users/authenticate. Use the returned token as a bearer token for reservation and search requests that require authorization.

Authorization: Bearer eyJhbGciOi...
Content-Type: application/json
Accept: application/json

Authentication

Authentication

Use the token endpoint to obtain a JWT. Keep credentials server-side and avoid storing tokens in public browser storage when possible.

POST/users/authenticate

Error Codes

Error handling

When reporting an integration issue, include the request URL, request body, response body, reservation number if available, and timestamp.

400Validation or missing input
401Missing or invalid token
500Server or vendor-side error
